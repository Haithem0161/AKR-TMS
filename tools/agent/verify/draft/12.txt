### 7.N The latest recon result of an issue's object and group (V-12-10-b, V-12-10-c, MEDIUM; DR-413)
`ReconRepository` (section 2) gains one read:
`async fn latest_result(&self, conn: &mut PgConnection, source_id: Uuid, rung: Rung, object: &str, group_key: &GroupKey) -> Result<Option<ReconResult>, RepoError>;`
It returns the `recon_results` row with this rung, object and group key from the most recent completed run of the source. Runs are ordered by `finished_at`, as section 3.1 `recon_sweep` step 1 orders day runs. It returns `None` when no completed run has such a row.
In block 7.5, "the latest recon result for its object and field" means this read. The issue stores its object as `<rung>:<object>` (section 3.1 step 8), so the read takes the rung and the object apart; the field is the group key. An issue of a kind other than `recon_break` has no recon result (section 3.5 step 1 allows those kinds). When the read returns `None`, `activate` writes no `accepted_delta`.
@@ END
