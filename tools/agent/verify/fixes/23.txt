### 7.N A repeat shred is a no-op (V-23-03-a, MEDIUM; DR-413)
`ShredOutcome { Shredded, AlreadyShredded }`. `EvidenceShredder::shred` on a row whose `shredded_at` is set returns `AlreadyShredded`, keeps the first `shredded_at` and writes no second `retention.evidence_shredded` event. Section 3.6 "sets `shredded_at = now()`" holds for the first call only.
@@ END

@@ BLOCK 23
### 7.N RelationshipEndResolver in section 2 (V-23-04-c, LOW; DR-413)
Section 2, services: `RelationshipEndResolver::end_date(conn, party_id: Uuid) -> Result<Option<NaiveDate>, RepoError>` (`akr-worker`). It gives the party end date of section 3.5, and `None` while the party is not due: the relationship is open, or the party has no customer and no account role.
@@ END

@@ BLOCK 23
### 7.N `feat.feature_runs` is purged by row (V-23-06-a, MEDIUM; DR-413)
Lead decision. Phase 13 does not partition `feat.feature_runs` (one row per month and feature), so a partition drop could never run. Its R4 handler is `record_purge` by age on `as_of`, in batches, as for `admin.quarantine_items`. Migration `0072` (section 1.2): the DELETE grant of `akr_retention` gains `feat.feature_runs`, and the table leaves the allow-list of `admin.retention_drop_partition`. The phase 13 assignment row takes the clock `age`.
@@ END

@@ BLOCK 23
### 7.N `assess.decisions` in the drop function, and the R7 exception (V-23-10-a, MEDIUM; V-23-10-b, LOW; DR-413)
The allow-list of `admin.retention_drop_partition` (section 1.2 step 1) names `assess.decisions` from this migration on. The table arrives with phase 29; until then step 2 refuses the name, because no partition is a child of it. Phase 29 therefore re-creates nothing. Class R7 is `report_only` (section 3.2 and 7.2) with this one exception: `assess.decisions` is R7 on a partition clock and leaves by partition drop under the rule of 7.2.
@@ END

@@ BLOCK 00
### 7.N Who creates the transit keys (V-23-09-a, MEDIUM; DR-413)
The transit keys of the OpenBao layout (section 3 and 7.6) are created once per install by the OpenBao ceremony runbook (SP-12), and by `make bao-dev` in development. No `akr-ctl` command creates a key; phase 23 named an `akr-ctl ops provision` that does not exist.
@@ END
