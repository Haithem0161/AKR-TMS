## Brief (decided 2026-10-06)

- AKR-TMS: AML + KYC risk and transaction monitoring product for many Iraqi banks (conventional + Islamic, private + state).
- Data: read-only connection to each bank's core banking system (CBS) database. Never the CBS backend. CBS-agnostic mapping layer.
- Optional screening API (later phase) that the bank's payment/SWIFT gateway can call before releasing a payment.
- Tech stack: same as /home/haithem/Projects/digital-banking-system (Rust/Axum, SQLx, PostgreSQL, Redis, MinIO, Vault, ORY, React 19, TanStack, Tailwind v4, K3s, Prometheus/Grafana/Loki).
